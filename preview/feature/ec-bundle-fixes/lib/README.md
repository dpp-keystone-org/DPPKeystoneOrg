# Internal Library (`lib/`)

This directory contains **project-internal** JavaScript modules and utilities.

These resources are heavily reused across the project's various web tools (Wizard, Validator, CSV Adapter) as well as the Node.js build scripts (e.g., `keystone-version.js`).

> **Note:** For *publicly reusable* developer SDKs and utilities meant to be consumed by external applications, see the [`../util/`](../util/) directory instead.
