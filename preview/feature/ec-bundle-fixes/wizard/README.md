# DPP Generation Wizard

The Wizard is an interactive, web-based tool designed to help users manually construct a valid Digital Product Passport.

**Features:**
*   **Sector Selection:** Choose a specific product sector and optional voluntary schemas.
*   **Form Generation:** Dynamically generates form inputs based on the required schema fields.
*   **JSON Generation:** Compiles the inputs into a compliant DPP JSON file.
*   **Transformations:** Allows users to transform the raw DPP into human-readable HTML (with or without embedded Schema.org markup) or standalone Schema.org data.
