# DPP Examples

This directory contains sample Digital Product Passports used for reference and testing.

*   **Fake Data Only**: All examples must use entirely fictional data.
*   **HTML Renderings**: Some examples include corresponding HTML versions to demonstrate how the semantic JSON-LD can be rendered as a human-readable web page.
*   **Assets**: Includes subdirectories for necessary assets, such as AI-generated, brand-less product images used in the examples.
