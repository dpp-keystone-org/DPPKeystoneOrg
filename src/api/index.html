DPP Keystone Validation & EC Battery Adaptation API

Interactive OpenAPI 3.1 reference for validating Digital Product Passports against both the patched EC Battery bundle (target=patched) and the unmodified official EC v1.0.0 bundle (target=raw), and adapting Keystone Battery DPPs into either format.

Download OpenAPI 3.1 Specification (openapi.yml)  |  Live Spec Endpoint

Quick Start (File-Based curl)

Replace path/to/battery-dpp.json at the end of either command with your local JSON file:

curl -X POST "https://dpp-keystone-api-naamukjlba-ew.a.run.app/adapt?target=patched&validate=true&mode=strict" \
  -H "Content-Type: application/json" \
  --data-binary @path/to/battery-dpp.json
curl -X POST "https://dpp-keystone-api-naamukjlba-ew.a.run.app/validate?target=patched&mode=strict" \
  -H "Content-Type: application/json" \
  --data-binary @path/to/ec-battery-dpp.json
